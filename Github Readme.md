# Valio - EV Calculator

Valio is an estimated value calculator that scours the sports betting market to find the bets with the most optimal estimated value. It uses AI to provide current form of players and teams in order to provide the most precise ev possible.

## -What is EV betting ?

In sports, estimated value is not the probability of an action being realised and it does not give the bets with the highest probability of passing. Rather, it is analysing probability and odds in order to place profitable bets in the long term.
